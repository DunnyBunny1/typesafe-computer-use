# Reliability summary — October 1, 2026

The fast Jev engine improved from 9/12 to **12/12** on the original MiniWoB++ task set and passed **60/60 cases across five rechecked seeds**. It passed **17/20 additional task families**. Median runtime on the original set was **1.97 seconds**, including browser startup and evidence capture; the previous fast baseline was 1.66 seconds at 9/12. These are adapted, repeated development-set measurements, not an official benchmark or SOTA score.

A headless JFK–SFO round-trip search for November 12–16, 2026 passed independent checks for dates, passengers, cabin and nonstop filtering in **15.18 seconds** of task-loop time. Local validation passed 826 unit tests, headless control/stale-source/no-submit checks, and packaging checks. Independent Spec, Security and Standards reviews were completed and their four findings fixed before final acceptance. GitHub Actions and native desktop acceptance were not run.

The remaining failures were copying a visual checkbox pattern, operating a slider and selecting an option in a custom dropdown. The fast engine uses observed browser controls without screenshot reasoning or drag support; an LLM recovery hint cannot supply a missing observation or executable action. The engine already requests occasional recovery hints, but those three cases still failed. Raw experiment results are retained locally and excluded from new commits; benchmark runners and regression fixtures remain available. The repository remains a TypeSafe fork incorporating MIT-licensed Browser Use Jev Ultrafast.
